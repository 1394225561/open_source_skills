# 实操记录模板

在用户确认的独立实操目录使用以下结构，按需创建。技能目录仅保存可复用方法和起始基线，不写实际客户资料与运行日志。

```text
实操目录/
  STATE.md
  experiments/
    E001.md
    G001.md
  reviews/
    YYYY-MM-DD-E001.md
    YYYY-MM-DD-G001.md
    YYYY-MM-DD-stage.md
```

日期使用实际当地日期，商业实验用 E 编号、独立成长练习用 G 编号，各自递增；同日多份复盘用递增后缀避免覆盖。用户有现成结构时优先沿用，已有记录只在需要时补字段，不批量重写历史。未知字段明确写“未知”，候选写“待确认”，不要把模板示例当成事实。结构展示的是可选文件，不一次全部创建；实验内的成长练习直接附在 E 文件，无商业实验时不创建空 E 文件。

## STATE.md

```markdown
# 当前实操状态
更新时间：
实操目录：

## 已确认背景与约束
- 主业状态：
- 必要家庭支出与安全线：
- 成熟业务收入目标（注明营业额或净收入）：
- 每周可投入时间：
- 当前实验或练习费用及时间上限：
- 可触达的人群与可用能力：

## 周期资源（明细汇总，共用费用只计一次）
- 周期起止日期及现金支出、工时上限：
- 累计实际支出、工时及明细来源：
- 尚未支付的已承诺费用、预计续费及待履行工时：
- 可新增现金与工时额度、未知项及核算日期：
- 已收款、待收款、已退款、应退未退与现金净流入：
- 未计入的成本、税费及收入核算口径：
- 共用支出明细（日期、项目、金额、是否已支付、对应周期）：
- 上周期汇总链接及承接的未完事项：

## 当前工作
- 当前入口：副业实验 / 成长练习
- 主要实验或练习及文件链接：
- 执行状态：草案 / 进行中 / 等待反馈 / 暂停 / 结束
- 业务阶段及依据（仅商业实验）：需求探索 / 交付与付费验证 / 重复成交验证 / 稳定经营验证
- 最新事实与证据来源：
- 当前判断及不确定性：
- 下一项具体行动、完成标准与约定日期：
- 尚待用户回答的一个关键问题：
- 暂停原因、待处理承诺与持续费用（如有）：
- 恢复条件或约定检查时点、过期动作的处理（如有）：

## 个人成长
- 当前重点能力及行为证据：
- 待验证的个人模式（不是诊断）：
- 支持与反对该解释的新证据：
- 当前支持办法、是否实际使用及观察结果：

## 长期积累与历史索引
- 可复用业务结论、适用范围、反证及来源：
- 可复用资产、使用限制及文件链接：
- 能力起点与近期独立表现、仍需帮助及证据链接：
- 陪练方式的调整、依据和待观察结果：
- 最近阶段复盘链接及下次回顾触发条件：
- 候选想法及暂不启动的理由：
- 已结束实验、成长练习与复盘链接：
- 重要更正（日期、原记录、修正依据）：
```

## reviews/YYYY-MM-DD-E001.md 或 YYYY-MM-DD-G001.md

```markdown
# 本轮复盘
日期与覆盖时段：
关联实验或成长练习：

## 行动事实
- 原定动作与实际完成：
- 新证据（含来源、时间窗口、分母）：
- 未执行、缺失数据、失败或异常：
- 商业或行为假设得到支持、被反驳还是仍未知：
- 主要卡点与其他可能解释：
- 对照预设条件的决定：

## 个人成长
- 当时对自己的解释或原话（用户未表达则不代填）：
- 感受与现实压力（如用户愿意讨论）：
- 哪些是事实，哪些仍是解释：
- 重点能力的具体进步、困难或反证：
- 支持办法是否实际用上、结果、独立程度及负担变化：
- 对原先个人模式假设的修正：

## 下一步
- 一个具体行动：
- 完成标准与预计耗时：
- 约定日期或复盘触发条件：
- 需要的支持：
```

成长复盘沿用以上结构，只填写行为证据，不要求客户数、收入或其他不适用商业指标。

## reviews/YYYY-MM-DD-stage.md（按需阶段复盘）

```markdown
# 阶段复盘
日期、覆盖时段、回顾触发原因与本次要作的决定：
- 关联实验、练习、周期与原始证据链接：
- 跨实验业务结论、适用范围、相反证据与未知（如适用）：
- 总投入、现金收支、工时、未完承诺及现实约束：
- 可保留或复用的资产、使用限制和链接：
- 能力起点与近期独立表现、得到的帮助、可迁移证据：
- 阻碍与支持办法的变化，个人模式假设的修正：
- 用户对陪练的反馈（未提供则未知）、观察依据及必要调整：
- 继续、调整、暂停或结束的决定与下一项行动：
- 回写 STATE 的摘要、来源链接及下次回顾触发条件：
```

每轮只填有信息的部分，保持记录短而可恢复。保存后核对文件存在、当前状态与实验或练习日志一致，投入汇总能追溯到明细；失败时报告未保存内容，不声称已经持久化。若用户未提供目录，交付本轮可复制记录并说明尚未落盘。
