# 诊断型内容方法

## 核心任务

高价值获客内容不是先证明作者厉害，而是帮助目标用户完成一次可靠的自我识别：

1. `原来我也处在这个问题里。`
2. `原来真正原因不是我先前理解的那样。`
3. `这个作者准确理解我的处境，而且给出的下一步可信。`

内容可以让人收藏，但诊断的准确性和证据才会形成信任。避免把“诊断”误写成对个人的医学、法律或财务结论；高风险领域只提供一般性识别框架，并明确专业求助边界。

## 五段诊断链

### 1. 场景

把人群放进一个能被观察的时刻：何时、何地、正在做什么、卡在哪里。优先使用具体动作和原话，少用“很多人都很焦虑”这类泛化开场。

### 2. 症状

列出用户能自查的信号。好的信号有区分度，用户能回答“有/没有”或给出频率；不要罗列人人都有的模糊感受。

### 3. 隐藏原因

提供新的解释模型。它必须同时解释多个症状，并能推出后续建议。只给问题换一个术语不算洞察。

### 4. 继续成本

说明不处理的现实后果，包括时间、机会、金钱、关系、情绪或风险。用条件化语言和合理时间尺度，不把最坏情况伪装成必然结果。

### 5. 证据

优先级从强到弱通常是：可核验结果与过程数据、可公开复现的演示、完整案例、带边界的个人经历、可信第三方资料、机制解释、主张本身。弱证据不能支撑强结论。

案例至少交代起点、约束、动作、周期、结果和不能归因的部分。匿名时删除可识别信息，但不要因此省略关键条件。

## 内容的一项主任务

每条内容只指定一个主要任务：

| 任务 | 用户变化 | 主要信号 | 常见 CTA |
|---|---|---|---|
| 触达 | 愿意停留并继续了解 | 有效播放、阅读深度、分享 | 查看下一条、关注系列 |
| 信任 | 接受新的问题解释 | 收藏、高质量评论、主页访问 | 收藏自查、评论处境 |
| 转化 | 愿意迈出商业下一步 | 私信、线索、预约、成交 | 私信关键词、预约评估 |
| 维系 | 已有受众得到持续价值 | 回访、复看、社群反馈 | 完成练习、汇报结果 |

次要收益可以存在，但不要让一条内容承担四套叙事和四个 CTA。

## 七种互动动机

一次最多选两个，且必须服务内容价值：

| 动机 | 可用设计 | 失真风险 |
|---|---|---|
| 想纠正你 | 呈现边界清晰、可讨论的判断 | 故意犯错、偷换概念 |
| 想代入你 | 使用具体处境、选择与情绪细节 | 编造经历、过度煽情 |
| 想看结果 | 先提出可验证目标，再展示过程与结果 | 只晒结果、隐去前提 |
| 想给你出招 | 留下真实开放决策点 | 伪装求助、消费善意 |
| 想看翻车 | 展示真实风险、试验或复盘 | 设计假事故、猎奇羞辱 |
| 想辨别真假 | 给出验证步骤、原始材料和限制 | 阴谋化、制造无依据怀疑 |
| 想证明自己 | 提供有区分度的小测验或判断题 | 优越感诱导、羞辱新手 |

## 从洞察到正文

先写以下一页论证，任一栏空缺都不急着扩写：

```text
目标人群：
具体场景：
可感症状：
旧解释：
新解释：
继续成本：
证据与边界：
可执行下一步：
主要内容任务：
互动动机（最多两个）：
单一 CTA：
看完后改变的一个判断：
```

正文可采用 `识别 -> 重构 -> 验证 -> 行动`：

- **识别**：用场景和症状让正确的人停下。
- **重构**：指出旧解释为何不够，给出更有解释力的原因。
- **验证**：用案例、演示、数据或机制证明，并说明边界。
- **行动**：给一个低摩擦自测或下一步，再给单一 CTA。

钩子必须由正文兑现。反常识只有在真实、有证据且对行动有帮助时使用。

## 信任与商业承接

- 内容给出“足够行动的一步”，服务提供“更快、更稳、更个性化或更完整的路径”；不要故意藏掉关键步骤制造咨询。
- CTA 强度匹配信任阶段。冷受众先自测或收藏，已有明确需求的受众再咨询或购买。
- 预先说明不适用人群，往往比扩大适用范围更能建立可信度。
- 用用户语言描述症状，用专业框架解释原因；不要反过来堆术语。
