# 实操记录模板

在用户确认的独立实操目录使用以下结构，按需创建。技能目录仅保存可复用方法和起始基线，不写实际客户资料与运行日志。

```text
实操目录/
  STATE.md
  experiments/
    E001.md
  reviews/
    YYYY-MM-DD-E001.md
```

日期使用实际当地日期，实验编号递增；同日多份复盘用递增后缀避免覆盖。用户有现成结构时优先沿用。未知字段明确写“未知”，候选写“待确认”，不要把模板示例当成事实。无实验时不创建空实验文件。

## STATE.md

```markdown
# 当前实操状态
更新时间：
实操目录：

## 已确认背景与约束
- 主业状态：
- 必要家庭支出与安全线：
- 成熟业务收入目标（注明营业额或净收入）：
- 每周可投入时间：
- 当前实验费用及时间上限：
- 可触达的人群与可用能力：

## 当前工作
- 主要实验及文件链接：
- 阶段与状态：探索 / 执行 / 等待反馈 / 暂停 / 结束
- 最新事实与证据来源：
- 当前判断及不确定性：
- 下一项具体行动、完成标准与约定日期：
- 尚待用户回答的一个关键问题：

## 个人成长
- 当前重点能力及行为证据：
- 待验证的个人模式（不是诊断）：
- 支持与反对该解释的新证据：

## 其他想法与历史索引
- 候选想法及暂不启动的理由：
- 已结束实验与复盘链接：
- 重要更正（日期、原记录、修正依据）：
```

## experiments/E001.md

```markdown
# E001：实验名称
建立日期：
状态：草案 / 进行中 / 暂停 / 结束

## 实验前约定
- 目标人群与触达来源：
- 具体问题及已知证据：
- 本次只优先验证的核心假设：
- 最小交付或内容：
- 执行动作与完成标准：
- 观察窗口与反馈可能延迟：
- 时间上限、费用上限、已获授权范围：
- 观察指标、分母、数据来源：
- 继续条件：
- 调整条件：
- 停止或暂停条件：
- 条件均未满足时如何判断证据不足：
- 本次重点练习的能力与可观察行为：

## 执行与证据日志（追加）
| 日期 | 计划或实际动作 | 完成状态 | 观察与样本量 | 来源或产物 | 时间与费用 | 未知或异常 |
| --- | --- | --- | --- | --- | --- | --- |

## 条件变更（追加，不覆盖原约定）
- 日期、新信息、修改理由、新条件与生效时间：

## 决策
- 继续 / 调整 / 停止 / 暂停 / 证据不足：
- 支持证据与反证：
- 累计实际费用和工时：
- 收款、退款、直接成本与净收益（无数据不估造）：
- 下一步及关联复盘：
```

## reviews/YYYY-MM-DD-E001.md

```markdown
# 实验复盘
日期与覆盖时段：
关联实验：

## 商业事实
- 原定动作与实际完成：
- 新证据（含来源、时间窗口、分母）：
- 未执行、缺失数据、失败或异常：
- 核心假设得到支持、被反驳还是仍未知：
- 主要卡点与其他可能解释：
- 对照预设条件的决定：

## 个人成长
- 当时对自己的解释或原话（用户未表达则不代填）：
- 感受与现实压力（如用户愿意讨论）：
- 哪些是事实，哪些仍是解释：
- 重点能力的具体进步、困难或反证：
- 对原先个人模式假设的修正：

## 下一步
- 一个具体行动：
- 完成标准与预计耗时：
- 约定日期或复盘触发条件：
- 需要的支持：
```

每轮只填有信息的部分，保持记录短而可恢复。保存后核对文件存在、当前状态与实验日志一致；失败时报告未保存内容，不声称已经持久化。若用户未提供目录，交付本轮可复制记录并说明尚未落盘。
