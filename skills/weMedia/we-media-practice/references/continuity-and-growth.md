# 恢复与成长方法

仅在中断恢复、行动受阻、独立成长练习或跨实验回顾时读取。记录使用现有 `STATE.md`、`experiments/` 和 `reviews/`，不另建一套日志。

## 中断后恢复

1. 从文件还原最后实际完成的动作、待反馈事项、暂停原因和恢复条件。未记录的活动询问用户，不推断中断期间没有行动。
2. 只核对会影响继续的变化：可用时间、精力、预算、主业家庭安排、意愿，以及未完成的客户承诺或持续费用。先问最关键的一项，已知情况不重复收集。
3. 检查原假设、渠道条件和观察窗口是否仍有效。旧窗口已过时保留原始数据及缺口，新观察另记窗口，不能拼接成连续执行的结果。
4. 根据证据及意愿选择恢复、缩小、继续暂停或结束。恢复和缩小时写明一个下一步、新日期、剩余额度及条件变更；不默认延长预算。继续暂停时写恢复条件或双方约定的检查时点，不强设恢复日期。
5. 过期动作标记为取消、替换或延期并保留原因，不要求补做全部任务。已有客户承诺必须单独处理；准备交付或延期沟通方案，不因暂停就视为义务已消失，发送仍依据现有授权。

保存暂停原因、待处理承诺、持续费用和恢复条件；结束时记录可保留资产。提醒仅在用户请求且调度工具可用时安排。

## 阻碍与独立成长练习

没有商业项目也可以开展成长练习。先明确用户想改善的具体场景，以及改善为何对其有用；不强迫转化成获客或赚钱任务。已有商业实验中的阻碍直接记录在该实验，不为同一练习重复建档。

每轮按实际需要完成以下判断，只问一个影响下一步的问题：

- **情境与事实：**上一次准备行动时发生了什么，原动作是什么，最终做了什么；保留用户原话和未知。
- **阻碍假设：**区分环境与资源限制、任务不清、技能缺口、触达不足、评价压力、目标已不再重要等解释，不能从未执行直接推出懒惰或恐惧。
- **一种支持办法：**选择与假设相符、用户愿意尝试的改变，明确何时何地或何种触发下做什么、完成标准、耗时上限和所需支持。
- **观察与决定：**记录支持办法是否实际用上、行为是否发生、负担有何变化，以及继续、调整、暂停或结束的理由。未尝试的办法不能判为无效，用户不同意某种练习也不算能力失败。

| 已知情境 | 可尝试的支持办法 | 检查什么 |
| --- | --- | --- |
| 工作时段反复被打断 | 协商现实可用的小段时间，准备中断后的续做标记 | 是否有可用时段、能否恢复；没有时间时调整计划 |
| 不知道从哪里开始 | 一起完成第一个实例，提供必要输入和完成标准 | 能否完成下一次相似动作 |
| 缺少具体技能 | 示例、有限练习、实际应用和反馈 | 能否在新任务中应用，而非只看完资料 |
| 想联系用户但没有名单 | 识别可接触人群，准备少量合适对象及邀约 | 对象是否匹配、能否在授权后实际触达 |
| 担心被评价，且用户愿意练习 | 先私下演练，再选择可承受的真实互动 | 是否尝试、具体困难是什么；不以获得好评为完成条件 |

这些是候选办法，不是诊断或固定处方。同一办法反复没有帮助时，回看它是否被尝试、假设是否有反证、支持是否合适，再更换方法、目标或资源安排。不要无限降低任务大小，也不要增加课程作为默认回应。现实资源不足或用户不愿继续时，可以休息、暂停或结束。

成长记录保留起点实例、练习产物、得到的帮助和后续独立表现；只有行为证据支持时才描述进步。一次完成不等于形成稳定能力，AI 代写产物也不等于用户已独立掌握。独立成长练习不填写虚构商业指标，不要求分享情绪或接受心理解释。

## 跨实验回顾与陪练调整

按主文件中的触发条件开展，不默认每天或每周增加一套流程。先确定这次需要作出的决定，再读取相关实验、练习和复盘；早期记录与当前状态矛盾时追溯更正和来源。

- **业务与资源：**找出重复出现的客户问题、有效渠道和交付模式，同时保留失败证据及适用范围；合计周期投入、持续费用、现金收支和工时，检查是否适合当前业务阶段。
- **资产与能力：**选择仍可使用的代码、内容、流程、案例等产物，保留链接及使用限制；对照起点与近期实例，记录独立完成程度、尚需帮助及能否用于新场景。不强迫复用已不适合的资产。
- **阻碍变化：**比较哪些支持办法被实际使用、在哪些情境有效或无效；更新个人模式假设，不能让旧基线盖过最新明确修正。
- **陪练效果：**结合用户反馈和行动记录检查建议是否可执行、是否减少决策负担，有无重复提问、过度规划或反复给无效建议。必要时调整提问方式、动作大小、支持形式或回顾频率，不以记录篇数、聊天频次或对建议的服从度衡量效果。

用户没有提供主观反馈时，标为未知，不代填满意度；没有可比证据时不编造进步趋势。每次只落实必要调整，将结论、反证、可复用资产、下一项调整及来源链接写入阶段复盘，并把精简摘要回写 `STATE.md`。周期转换保留旧周期记录，未付承诺和持续费用不能随周期重置消失。
