# 平台成品规范

## 先适配媒介，再填内容

不要把同一段文字机械搬到所有平台。先确认平台、内容形态、目标动作和用户的制作条件；平台规格会变化，涉及尺寸、时长、标签数量、商业内容标识等当前规则时应查询官方资料。

## 通用发布包

当前版本目录必须包含三个互相一致的文件：

### `正文.md`

- 内容论证页
- 备选标题与最终标题
- 完整正文、口播稿或逐页文案
- 证据脚注/来源和断言边界
- 最终 CTA

### `制作单.md`

- 平台、比例、预计时长/页数和技术规格
- 镜头/页面/段落编号
- 每段的信息任务、画面、台词/字幕、节奏和转场
- 必需素材、已有素材、待制作素材及授权状态
- 封面/首帧设计与可读性要求
- 录制、剪辑、配乐、音效、字幕和导出检查

### `发布包.md`

- 最终标题
- 封面文案或首屏文字
- 可直接发布的配文
- 单一 CTA
- 必要的关键词、话题标签、提及或链接占位
- 图片替代文本或视频内容摘要
- 置顶评论（确有用途时）
- 发布前合规与事实核验结果
- 发布版本号和发布后待记录项

## 形态适配

### 短视频

首个画面与第一句话共同完成受众筛选。逐镜脚本至少记录：镜头编号、时段、景别/动作、口播、屏幕文字、素材、声音和剪辑意图。画面应提供证据、演示或理解增量，不只是把口播逐字贴成字幕。

### 图文或轮播

首图承担“人群 + 场景 + 问题”的识别。每页只完成一个信息任务，页间形成因果推进；结尾给自测、清单或下一步。制作单写明每页标题、正文、图示、素材和层级，不以密集小字代替编辑。

### 长文

标题和导语明确问题边界；用小标题组织诊断链，案例放在其能够证明的论点旁。为略读者提供可扫描的症状、判断规则和行动项，同时保留推理过程。

### 直播或长视频

用章节和时间段组织：承诺、诊断、解释、演示/案例、问答、行动。预先列出可能误解、证据展示方式和互动节点。不要用重复预告拖延兑现核心内容。

## 最终检查

- **识别**：目标用户能在首屏确认内容与自己有关。
- **兑现**：标题承诺在正文中得到完整回答。
- **理解**：场景、症状、原因和建议之间存在清楚因果。
- **证据**：数字、案例、截图、引用和素材来源可追溯。
- **制作**：每个画面或页面都能按制作单执行，无模糊占位。
- **可读**：字幕、封面和小屏文字不会溢出，关键信息不被 UI 遮挡。
- **声音**：人声清楚，音乐和音效不掩盖信息；无授权风险。
- **行动**：只有一个主要 CTA，且与内容任务和信任阶段匹配。
- **合规**：隐私、版权、广告披露、行业限制与平台规则均已检查。
- **留痕**：发布包标明题目编号和版本号。
