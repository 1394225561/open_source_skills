# 工作区与留痕协议

## 目录契约

```text
<赛道>-自媒体/
|-- workspace.json
|-- 工作区说明.md
|-- 赛道档案.md
|-- 选题棋盘.md
|-- 选题台账.csv
|-- 运营实验.md
`-- topics/
    `-- TYYYYMMDD-NNN/
        |-- 选题简报.md
        |-- 变更记录.md
        |-- 反馈.csv
        |-- 复盘.md
        `-- versions/
            `-- v001/
                |-- 正文.md
                |-- 制作单.md
                `-- 发布包.md
```

`workspace.json` 是工作区身份和结构版本的机器可读记录。不要把业务内容塞进去。`选题台账.csv` 是跨选题索引；选题目录是正文、版本、证据和反馈的完整事实来源。

## 状态定义

台账中的 `status` 只使用以下值：

| 状态 | 含义 |
|---|---|
| `selected` | 用户已确认，尚未完成首稿 |
| `drafting` | 正文或制作单正在形成 |
| `review` | 正在核验内容、证据或制作可行性 |
| `ready` | 发布包完整，但尚未确认发布 |
| `published` | 已获得实际发布时间和链接/平台记录 |
| `measuring` | 正在按窗口采集反馈 |
| `iterated` | 已复盘并形成下一版本或下一选题 |
| `archived` | 明确不再推进，并记录原因 |

状态不能因为“预计会发布”而改成 `published`。阻断或放弃要在 `变更记录.md` 写明，不静默跳过。

## 版本规则

- 题目编号由脚本生成，格式为 `TYYYYMMDD-NNN`，当天从 `001` 递增。
- `new-topic` 创建 `v001`；任何会改变对外内容的改稿，先用 `new-version` 复制当前版本，再在新版本修改。
- 排版纠错若发生在发布前且不改变含义，可在当前版本修正并在变更记录注明；发布后任何变化都必须新建版本。
- `变更记录.md` 写清版本、日期、修改目的、依据和实际变化。不要只写“优化文案”。
- 台账的 `current_version` 指当前编辑版本，`published_version` 指实际发布版本，两者可以不同。

## 选题台账字段

脚本维护基础字段：`topic_id,title,platform,format,goal,status,current_version,published_version,created_at,published_at,post_url`。修改字段时保持 CSV 可解析，不在单元格中手工拼接未转义换行。

## 反馈记录

`反馈.csv` 每一行对应一个采集窗口，而不是覆盖累计值。默认观察窗口可使用发布后 2 小时、24 小时、72 小时和 7 天；若平台节奏不同则调整并写明。

字段分五层：

- 曝光：`impressions`。
- 消费：`views_or_reads`、`avg_watch_or_read`、`completion_rate`。
- 互动：`likes`、`comments`、`saves`、`shares`。
- 关系：`profile_visits`、`follows`、`direct_messages`。
- 业务：`leads`、`conversions`、`revenue`。

不适用或拿不到的数据留空，不填 0。`qualitative_notes` 记录高信息量反馈的摘要，原话和隐私处理方式写入 `复盘.md`。不同平台指标定义不一致，不做未经校准的直接比较。

## 复盘结构

`复盘.md` 分开记录：

1. **事实**：版本、发布时间、观察窗口、数据、受众原话、异常事件。
2. **解释**：哪些环节可能影响结果，并标注信心高/中/低。
3. **判断**：内容任务是否完成；不要用曝光指标证明转化，也不要用单次成交证明稳定规律。
4. **动作**：保持、停止、修改或新增的假设；对应到棋盘格、正文段落或制作环节。
5. **下一测试**：一次尽量只改变一个关键变量，并定义成功信号。

## 一致性检查

每次阶段结束核对：

- 台账中的编号、状态和版本与目录一致；
- `发布包.md` 标注的版本等于 `published_version`；
- 每个关键断言能回到来源或被明确标为经验/假设；
- 反馈带观察时间，不把不同累计窗口当成独立新增量；
- 棋盘调整能追溯到哪次发布、哪条反馈或哪项新事实。
