# 平台与受众适配

## 先决定为谁写、在什么入口被看见

平台基调只是起始假设。优先采用用户指定的定位、账号实际反馈和本次场景；不要用全站性别、年龄或城市比例代替目标人群，更不能据此推断个人偏好。只补会改变写法的信息，不额外生成平台研究报告。

在已有选题简报中用几行记录以下决策及依据（用户提供、实际反馈、可追溯资料或待验证假设），不另建表单：

| 维度 | 需要做出的创作决定 |
|---|---|
| 人群与任务 | 谁在什么场景遇到什么问题；已有知识、预算、时间或操作条件如何影响术语、案例和步骤 |
| 触达入口 | 推荐浏览先建立相关性；主动搜索先回答具体问题；关注页或老用户可承接已有背景，减少重复解释 |
| 需求与信任阶段 | 尚未意识到问题、比较方案还是准备行动；决定先解释、展示对比还是交付操作步骤，以及 CTA 强度 |
| 基调与表达 | 同伴经验、专业解释、现场演示或故事观察；明确用词、情绪强度、信息密度和视觉/声音的任务 |
| 证据与形态 | 用何种材料支撑判断，受众需要看过程、查参数还是跟步骤；结合出镜、素材、设备和制作时间选形态 |
| 主任务与验证 | 沿用一个主要内容任务，选可取得的成功信号；指标用于验证适配假设，不冒充推荐算法权重 |

## 两个平台的条件化写法

以下是供本次内容试用的表达路径，不是全站用户画像或流量承诺。同一平台的不同入口与人群可以采用不同写法。

| 决策 | 小红书：以生活问题、经验参考或决策需求为切入点时 | 抖音：面向推荐浏览、尚未明确需求的人群时 |
|---|---|---|
| 标题与开头 | 写清对象、场景、约束或具体问题，使用受众会搜索的自然用语；尽早给出参考价值 | 用可识别的动作、症状、真实结果或有边界的问题建立相关性，尽早兑现；不必强行制造冲突 |
| 叙述与语气 | 用具体条件、取舍和使用细节支持经验感；专业内容仍应说明依据，不假装亲历 | 用易听懂的短句配合演示，减少重复铺垫；按理解难度安排节奏，不强制快剪、反转或高情绪 |
| 证据与信息顺序 | 适用条件、步骤/比较、短板与边界便于回查；视频配文可补关键步骤和检索词 | 尽早展示关键证据，再解释过程与限制；字幕突出判断点，不能因追求节奏删掉前提 |
| 互动与承接 | 需要日后使用时提供可保存的清单；比较阶段可邀请反馈具体条件 | 先兑现当前内容承诺；再按信任阶段选择自测、反馈、关注系列或咨询等一个动作 |

反向校正：抖音搜索场景同样应直接回答问题、提供可回查信息；小红书推荐浏览也需要迅速说明相关性。老用户不必每次从痛点教育开始，专业受众可以保留必要术语。其他平台沿用上表前的决策维度，根据用户上下文推导写法，不硬套这两个平台的预设。

## 按信息任务选形式

用户已指定形态时优先遵从。未指定时，推荐一个主形态并说明理由；只有实质取舍才补一个备选，不默认制作所有形式。

- **步骤、清单与多项比较**：图文、轮播或长文便于查阅；动作难以用文字解释时选演示视频。
- **操作、变化与实测过程**：实拍教程、测评、过程记录或 Vlog；前后对比交代条件和周期，不把差异直接说成因果。
- **观点、经验复盘与解释**：口播配必要证据；不出镜时可用旁白加真实素材，不强制真人出镜。
- **氛围与短暂瞬间**：照片、短片或平台可用的动态照片；不承担复杂步骤教学。使用具体功能前确认账号可用性。
- **真实开放问题**：问答可作为图文或视频的叙事方式；不能为互动编造求助。
- **持续主题或深入互动**：系列/合集是组织方式，直播是交付形式，均不作为单条创作的必选项；日常动态只在确有维系需求且功能可用时使用。

剧情、沉浸式、口播属于表现手法；AI 生成属于制作方式。先选适合的信息载体，再选择手法与工具，不能把“AI 视频”本身当成受众价值。

## 跨平台改写

保留事实、证据边界、核心判断和品牌承诺；按各平台本次受众与入口重写开头、信息顺序、例子详略、语气、证据呈现及 CTA。只制作用户要求的平台版本，复用研究与素材，不重复整套选题流程。使用工作区管理多个平台发布包时，各平台用独立选题记录并在简报中关联来源，避免共用一个发布状态或链接。

例如，同一条“租房书桌收纳”内容，若小红书版本面向主动找方案的人，可从“免打孔、小桌面怎么留出工作区”切入，逐页列约束和操作；若抖音版本面向浏览中的新受众，可先展示桌面被物品占满的动作和整理过程，再解释取舍。若两边都是搜索用户，保留直接答题的结构即可，不为了差异硬加反转。没有实测时两边都不能编造效果数据。

## 资料取舍与核验边界

- 吸收参考资料中的场景、形式与表达启发；无可追溯出处的用户比例、流量占比、最佳时长、算法权重、扶持或限流结论不作为规则或事实使用。
- 只有本次成品依赖当前功能、规格或规则时才定向核验，优先官方资料并记录适用日期和范围。统计画像还需注明样本与口径；账号数据不外推为全平台规律。
- 核验不了的说法删去、降为明确假设或采用不依赖该功能的方案；只有影响真实性、合规或交付可用性的缺口才阻断相应部分。
- 商业内容按适用要求清楚披露，不吸收“把广告藏起来”的建议；AI 标识同样依据当前适用规则处理，不承诺加标识即可获得推荐。
