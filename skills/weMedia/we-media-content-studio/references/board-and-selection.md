# 选题棋盘与决策

## 25 格结构

使用 5×5 坐标，`C3` 是赛道，`B2:D4` 除 `C3` 外的 8 格是相关内容，外围 16 格是具体人群与使用场景。

```text
      1      2      3      4      5
A   外圈   外圈   外圈   外圈   外圈
B   外圈   内圈   内圈   内圈   外圈
C   外圈   内圈   赛道   内圈   外圈
D   外圈   内圈   内圈   内圈   外圈
E   外圈   外圈   外圈   外圈   外圈
```

中心不要只写宽泛行业名。尽量写成 `服务对象 + 问题域/结果域`，例如“独立咨询师的内容获客”，而不是“营销”。若用户只提供宽泛行业，保留其原话，同时在 `赛道档案.md` 把更窄表述标为暂定假设。

## 填格规则

### 内圈 8 格：行业相关内容

优先覆盖互不重复的决策域，而不是八个同义词。可从以下角度选择真正适用的八项：

- 入门认知与误区
- 问题诊断与评估
- 方法、流程与工具
- 案例、拆解与结果
- 成本、风险与避坑
- 选择、比较与决策
- 实施、维护与优化
- 趋势、规则与行业变化

这些是启发式类别，不强制每个赛道照抄。每格写用户会关心的具体内容域。

### 外圈 16 格：人群及场景

每格同时包含“谁 + 在什么时刻/任务中”，避免只写人口标签。让 16 格分布在不同阶段、成熟度和约束下，例如：刚意识到问题、首次尝试、比较方案、实施受阻、出现结果、复盘优化；同时覆盖预算、时间、能力、组织角色等差异。

检查重复：如果两个格子的用户会说同一句话、面临同一个决定，应合并并补一个不同场景。

## 三点一线的几何边界

5×5 外圈有 16 格，但从 `C3` 出发并穿过一个相邻内圈格的严格格点射线只有 8 条：

| 严格射线 | 内圈 | 外圈锚点 |
|---|---|---|
| 西北 | B2 | A1 |
| 北 | B3 | A3 |
| 东北 | B4 | A5 |
| 西 | C2 | C1 |
| 东 | C4 | C5 |
| 西南 | D2 | E1 |
| 南 | D3 | E3 |
| 东南 | D4 | E5 |

因此输出两组候选：

1. **严格射线候选**：中心 + 内圈 + 8 个锚点，保留用户的“三点一线”原意。
2. **扩展场景候选**：其余 8 个外圈格与语义最相关的内圈格组合，标记为“扩展映射”，不声称几何共线。

每个组合不是标题，而是选题方向：`为[人群]在[场景]下，解释[内容域]中的[问题/决策]`。再从方向推导多个表达角度。

## 候选卡

对最有潜力的方向形成候选卡：

```text
候选编号：
路径：中心 -> 内圈 -> 外圈
类型：严格射线 / 扩展映射
目标人群与场景：
可感症状：
可能的隐藏原因：
继续成本：
现有证据：
主要内容任务：
建议互动动机：
暂定平台与形态：
一句话选题：
```

## 选择维度

用 1-5 分做相对比较，并同时展示理由；不要只给总分：

- **受众贴合**：是否对应一个明确且可触达的人群。
- **痛点强度**：问题是否正在发生，并带来可感成本。
- **认知增量**：隐藏原因是否能改变旧理解。
- **证据可得**：能否在本次内容中可信证明。
- **平台表现**：该场景是否适合目标平台与形态。
- **商业衔接**：是否自然连接用户能提供的价值。
- **风险扣分**：事实不稳、合规敏感、隐私或争议误导风险。

优先选“有受众、有认知增量、有证据”的方向。高互动潜力不能抵消证据缺失。

## 棋盘迭代

棋盘是内容假设地图，不是一次性脑暴图。每轮复盘后：

- 保留表现稳定且与商业目标一致的格子；
- 将高质量评论中的新场景加入候选池，必要时替换重复格；
- 区分选题疲劳与表达失败，同一方向至少在证据、角度或形态有实质变化时再测；
- 在 `选题棋盘.md` 的修订记录中写日期、改动、依据和影响的候选路径。
